# Lucky Draw Studio

Lucky draw system for company events (Kumpulan Yayasan Sabah). Top management wants a
**different name-draw animation every draw**, so the app is a hub that launches one of
many separate design pages. Current goal: smoother, more polished animations, and more designs.

## Structure
- `index.html` — hub: prize for next draw, design cards ("Used n× / Not used yet" badges),
  "Surprise me" (random among least-used, never the last one), shared Names list,
  Winners log (name, prize, design, time), Copy list.
- `core.js` — shared by every page (`window.LD`): names list + winners log in localStorage
  (key `ld-studio-v1`), fair crypto-random pick, easing + tween helpers, Web Audio sound kit,
  2D confetti, `fitText`, keyboard/clicker shortcuts (Space / Enter / PageDown / → = draw,
  F = full screen, H = hub), and `LD.stage()` which runs the Draw → animate → record → New draw flow.
- `designs/*.html` — one page per design. `designs/ui.css` = shared frame for the newer designs.

## Running
Pages share localStorage, so serve the folder over HTTP rather than opening files directly:
`npx serve .` or `python -m http.server 8000`, then open http://localhost:8000.
Libraries are bundled in `vendor/` (no internet needed for them), mapped in each page's import map:
- `vendor/three/` — three r160 `build/three.module.js` + only the addons in use under `examples/jsm/` (OrbitControls, RoomEnvironment,
  EffectComposer/RenderPass/UnrealBloomPass/OutputPass/ShaderPass/MaskPass/Pass, Reflector, Copy/LuminosityHighPass/Output shaders).
  A new `three/addons/...` import needs its file (and its relative imports) copied from the three@0.160.0 npm package.
- `vendor/gsap/` — gsap 3.13.0 ESM build, all plugins (SplitText, CustomEase, …). Import map: `"gsap": "../vendor/gsap/index.js"`,
  `"gsap/": "../vendor/gsap/"`, then `import { CustomEase } from 'gsap/CustomEase.js'`.
- `vendor/fonts/` — Google Fonts copied locally (latin + latin-ext subsets only; WOFF2 files in `files/`). One stylesheet per page:
  `hub.css` for index.html, `<design>.css` for each design. Nothing in the studio needs internet now.
  To add or change a page's fonts: put a normal Google Fonts `<link rel="stylesheet" href="https://fonts.googleapis.com/css2?...">`
  in the page, then run `python -I tools/bundle_fonts.py .` from the project folder — it downloads the files and swaps the link for the local CSS.
Testing tip: the in-app browser pane throttles or pauses requestAnimationFrame while hidden, so check motion by pausing the GSAP
timeline and seeking it in fixed steps (see `#debug`), and restore `ld-studio-v1` in localStorage after test draws.
Gotcha: Three's `curve.getPoint()` is not arc-length parameterised — use `getPointAt()` for camera flights or speed jumps at segment joins.

## Animation libraries / skills
- Three.js r160 for 3D designs.
- GSAP is 100% free incl. SplitText, MorphSVG, CustomEase, ScrambleText. Official agent skills:
  https://github.com/greensock/gsap-skills — installed in `.claude/skills/gsap-*`.
- Other project skills in `.claude/skills/` (use them): frontend-design; threejs-shaders / -postprocessing / -materials /
  -animation; improve-animations, review-animations, animation-performance; better-typography; accessibility; find-skills
  (search more with `npx skills find <topic>`; vet installs + GitHub stars before adding).
- Tone: Sabah state-level event with foreign heads of state — ceremonial and restrained, never playful or casino-like.
  New concept proposals: `concepts/state-concepts.html`.
- Rules: timelines over chained delays; animate transforms/opacity, not layout props;
  register plugins once; split text only after fonts load.

## Smoothing rules (keep applying)
- Frame-rate-independent motion (clamp dt).
- Transforms/opacity only.
- Decelerations whose start speed matches the cruise speed (no jolt at hand-off).
- Short overshoot/settle at the stop.
- Honour `prefers-reduced-motion`.

## Adding a design
Copy a newer page (e.g. `wheel.html`), set `data-design="newid"`, add `{ id, title }` to
`DESIGNS` in core.js and a card entry in `INFO` in index.html. Implement `draw(winner)` and
`reset()` inside `LD.stage({...})`. Winner selection stays in core.js — designs only animate
to the winner they are given.
